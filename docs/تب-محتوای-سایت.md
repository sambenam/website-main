## همگام‌سازی با محصولات

این بخش از قبل وجود داشت و قرارداد شناسه را هم درست رعایت می‌کرد:

```
ویدیو  →  محصول با شناسه  <itemId>-video
فایل   →  محصول با شناسه  <itemId>
```

اما سه تفاوت با تب محصولات داشت که رفع شد:

### ۱. لینک آپارات به‌عنوان فایل ذخیره می‌شد

اگر ادمین لینک آپارات را می‌چسباند و منوی provider روی «file» می‌ماند، مقدار `file` ذخیره می‌شد و صفحه مطلب یک تگ `<video>` خالی رندر می‌کرد.

حالا نوع لینک خودکار تشخیص داده می‌شود — همان رفتاری که در تب محصولات پیاده شده بود:

```
aparat.com/v/xxx    →  provider: "aparat"
youtube.com/watch   →  provider: "youtube"
لینک مستقیم         →  انتخاب خود اپراتور حفظ می‌شود
```

منوی provider هم موقع خروج از فیلد به‌روز می‌شود تا اپراتور ببیند چه چیزی تشخیص داده شده.

### ۲. حجم فایل هاردکد بود

```js
fileSize: "15MB"; // برای هر ویدیویی، حتی آپارات
```

یک ویدیوی آپارات اصلاً حجم دانلود ندارد. حالا خالی می‌ماند مگر اینکه مقدار واقعی موجود باشد.

### ۳. محصول از `appApi` رد نمی‌شد

مستقیم در `localStorage` نوشته می‌شد، پس با آمدن بک‌اند به سرور نمی‌رسید. حالا مثل بقیه پروژه از `appApi.admin.products` عبور می‌کند.

### ۴. فیلد `contentId`

محصولات ساخته‌شده از این تب حالا `contentId` دارند تا سرور مجبور نباشد شناسه را تجزیه کند — همان کاری که تب محصولات می‌کند.

## جریان کامل

```
ویرایش آیتم → افزودن ویدیو/فایل → ذخیره
        ↓
   ┌────────────────────┬─────────────────────┐
محتوای مطلب          محصول در تب محصولات
(صفحه تک‌مطلب)        (قابل فروش با قیمت)
```

و برعکسش هم کار می‌کند: محصولی که از تب محصولات ساخته شود، در محتوای همان مطلب می‌نشیند.

## بخش فایل‌های دانلودی در ویرایشگر

قبلاً یک ردیف ساده از چهار جعبه متن بود، بدون هیچ راهنمایی درباره اینکه آدرس فایل را از کجا بیاورد.

حالا هر ردیف همان ساختار فرم محصول را دارد:

```
┌─ فایل ۱ ──────────────────────────────── [حذف] ─┐
│ عنوان فایل            نوع فایل                   │
│                                                  │
│ ◉ فایل روی هاست خودتان                          │
│ ○ لینک از فضای ابری                             │
│ ○ آپلود از دستگاه — نیازمند سرور   [غیرفعال]    │
│                                                  │
│ آدرس فایل            [بررسی]                    │
│ راهنما: فایل را در پوشه files هاست بگذارید...   │
│                                                  │
│ حجم فایل (اختیاری)                              │
└──────────────────────────────────────────────────┘
```

### رفتارها

| کار                  | نتیجه                                      |
| -------------------- | ------------------------------------------ |
| تعویض منبع           | راهنما و placeholder عوض می‌شود            |
| تایپ لینک گوگل درایو | تشخیص داده و توضیح داده می‌شود             |
| خروج از فیلد         | لینک اشتراکی به دانلود مستقیم تبدیل می‌شود |
| حجم بالای ۵۰ مگابایت | هشدار پیشنهاد فضای ابری                    |
| دکمه بررسی           | با درخواست HEAD وجود فایل را چک می‌کند     |

گزینه «آپلود از دستگاه» عمداً نمایش داده ولی غیرفعال است، تا اپراتور بداند این قابلیت در راه است و دنبالش نگردد.

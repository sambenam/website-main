# راهنمای افزودن محصول — برای مدیر و ادمین

این سند برای کسی نوشته شده که با سرور و بک‌اند کار نمی‌کند.

---

## خلاصه یک‌خطی

| چه چیزی                      | کجا بگذارید                         |
| ---------------------------- | ----------------------------------- |
| 🎬 **ویدیو**                 | آپارات — همیشه، بدون استثنا         |
| 📄 **فایل زیر ۱۰ مگابایت**   | هاست خودتان (سی‌پنل ← File Manager) |
| 📦 **فایل بالای ۵۰ مگابایت** | فضای ابری ایرانی (آروان، لیارا)     |
| 🖼️ **تصویر محصول**           | مستقیم از پنل انتخاب کنید           |

## ویدیو → آپارات

### چرا آپارات و نه سرور خودمان؟

یک ویدیوی ۵۰۰ مگابایتی که ۱۰۰ نفر ببینند، **۴۹ گیگابایت** ترافیک مصرف می‌کند. سهمیه ماهانه هاست معمولی ۱۰ تا ۱۰۰ گیگابایت است — با یک ویدیو نصف سهمیه می‌رود.

آپارات علاوه بر رایگان بودن:

- **پخش تدریجی** — بیننده از ثانیه اول می‌بیند، لازم نیست کل فایل دانلود شود
- **کیفیت خودکار** — کاربر با اینترنت ضعیف نسخه سبک‌تر می‌گیرد
- **سرور در چند شهر ایران** — سریع‌تر از هاست شما

### مراحل

۱. وارد [آپارات](https://www.aparat.com) شوید و ویدیو را آپلود کنید
۲. اگر می‌خواهید فقط خریداران ببینند، هنگام آپلود گزینه **«خصوصی»** را بزنید
۳. بعد از پردازش، نشانی صفحه ویدیو را کپی کنید:

```
https://www.aparat.com/v/aBc12
```

۴. در پنل: **محصولات ← افزودن محصول**
۵. منبع فایل را روی **«ویدیو از آپارات یا یوتیوب»** بگذارید
۶. لینک را در فیلد بچسبانید

پنل خودش تشخیص می‌دهد و پیام تأیید نشان می‌دهد. ویدیو با پخش‌کننده آپارات روی صفحه مطلب نمایش داده می‌شود.

> لازم نیست لینک مستقیم فایل ویدیو را پیدا کنید — همان نشانی صفحه کافی است.

## فایل → هاست خودتان (روش اصلی در ایران)

گوگل درایو و دراپ‌باکس در ایران بدون فیلترشکن باز نمی‌شوند، پس عملاً برای کاربران شما بی‌فایده‌اند. روش درست، آپلود روی هاست خودتان است.

### مرحله به مرحله با سی‌پنل

**۱. ورود به سی‌پنل**

```
yourdomain.ir/cpanel        یا        yourdomain.ir:2082
```

نام کاربری و رمز را شرکت هاستینگ موقع خرید به شما داده است.

**۲. باز کردن File Manager**

در بخش **Files** روی **File Manager** کلیک کنید.

**۳. رفتن به پوشه سایت**

وارد پوشه `public_html` شوید. این همان پوشه‌ای است که فایل‌های سایتتان در آن است.

**۴. ساختن پوشه فایل‌ها (فقط بار اول)**

روی **+ Folder** بزنید و پوشه‌ای به نام `files` بسازید. همه فایل‌های فروشی را همین‌جا نگه دارید تا مرتب بماند.

**۵. آپلود**

وارد پوشه `files` شوید، روی **Upload** بزنید، و فایل را انتخاب کنید. صبر کنید تا نوار سبز شود و کلمه **Complete** ظاهر شود.

> اگر چند فایل دارید، اول با WinRAR فشرده‌شان کنید و یک فایل ZIP آپلود کنید. بعد در سی‌پنل روی آن راست‌کلیک و **Extract** بزنید.

**۶. نوشتن آدرس در پنل**

حالا در فرم افزودن محصول، در فیلد آدرس فایل بنویسید:

```
../files/course-101.pdf
```

یعنی نام همان فایلی که آپلود کردید، با `../files/` در ابتدا.

---

**۷. بررسی آدرس**

کنار فیلد آدرس، دکمه **«بررسی»** هست. بزنیدش تا همان‌جا معلوم شود فایل واقعاً در آن آدرس هست یا نه:

| پیام                              | یعنی                                         |
| --------------------------------- | -------------------------------------------- |
| ✅ فایل پیدا شد (حدود ۱۲ مگابایت) | همه‌چیز درست است                             |
| ⚠️ فایلی در این آدرس نیست         | نام فایل را اشتباه نوشته‌اید                 |
| ⚠️ دسترسی به فایل بسته است        | مجوز فایل را در سی‌پنل درست کنید             |
| ℹ️ بررسی ممکن نشد                 | آدرس روی دامنه دیگری است؛ ممکن است درست باشد |

بدون این دکمه، یک غلط تایپی تا لحظه‌ای که مشتری روی دانلود کلیک کند پنهان می‌ماند.

---

### 🔒 نکته امنیتی مهم

فایلی که در `public_html` بگذارید، **با آدرس مستقیم برای همه قابل دانلود است** — حتی کسی که نخریده.

تا وقتی بک‌اند وصل نشده، این راه‌حل موقت را به کار ببرید: **نام فایل را غیرقابل حدس کنید.**

```
❌ ../files/hesabdari.pdf          حدس زدنش ساده است
✅ ../files/hesabdari-a8f3d9c2.pdf  عملاً غیرقابل حدس
```

آن رشته تصادفی را می‌توانید از هر تولیدکننده رمز آنلاین بگیرید. این محافظت کامل نیست (کسی که خریده می‌تواند لینک را بفرستد) ولی جلوی دانلود تصادفی را می‌گیرد.

راه‌حل واقعی، **لینک موقت امضاشده** است که بک‌اندکار باید پیاده کند — توضیحش در `docs/آپلود-فایل-محصول.md` هست.

## فایل بزرگ → فضای ابری ایرانی

اگر فایلی بالای ۵۰ مگابایت دارید (مثلاً پکیج ZIP چند دوره):

| سرویس          | فضای رایگان               | توضیح                     |
| -------------- | ------------------------- | ------------------------- |
| **آروان‌کلاد** | ۵ گیگ فضا + ۲۰ گیگ ترافیک | ایرانی، سازگار با S3      |
| **لیارا**      | ۲.۵ گیگ                   | ایرانی، مستندات فارسی خوب |
| **ایران‌سرور** | —                         | از ماهی ۴۶ هزار تومان     |

هر سه لینک مستقیم می‌دهند که همان را در فرم وارد می‌کنید. ترافیک از سهمیه آن‌ها کم می‌شود، نه هاست شما.

## گوگل درایو و دراپ‌باکس

پنل این‌ها را هم پشتیبانی می‌کند و لینکشان را خودکار به دانلود مستقیم تبدیل می‌کند. اما **برای کاربران ایرانی توصیه نمی‌شود** چون بدون فیلترشکن باز نمی‌شوند.

اگر مخاطبتان خارج از ایران است، این گزینه‌ها هم کار می‌کنند.

## تصویر محصول

در مودال **ویرایش محصول**، دکمه **«انتخاب تصویر از دستگاه»** را بزنید.

| نکته            | مقدار                |
| --------------- | -------------------- |
| اندازه مناسب    | حدود ۶۰۰ × ۶۰۰ پیکسل |
| حداکثر حجم فعلی | ۳۰۰ کیلوبایت         |
| فرمت پیشنهادی   | WebP یا JPG          |

### چرا سقف ۳۰۰ کیلوبایت؟

تا وقتی سرور وصل نشده، تصویر داخل مرورگر ذخیره می‌شود و جای زیادی ندارد. مهم‌تر اینکه **تصویر در هر بازدید لود می‌شود** — برخلاف فایل که فقط بعد از خرید دانلود می‌شود.

صفحه‌ای با ۱۲ تصویر:

| حجم هر تصویر                 | حجم صفحه     | زمان لود با اینترنت ضعیف |
| ---------------------------- | ------------ | ------------------------ |
| ۴ مگابایت (مستقیم از موبایل) | ۴۷ مگابایت   | **۲۵۶ ثانیه**            |
| ۵۰۰ کیلوبایت                 | ۵.۹ مگابایت  | ۳۲ ثانیه                 |
| ۶۰ کیلوبایت (بهینه)          | ۷۲۰ کیلوبایت | **۴ ثانیه**              |

تفاوت **۶۵ برابر** است.

### فشرده کردن تصویر

اگر تصویرتان بزرگ است، با یکی از این‌ها کوچکش کنید:

- [squoosh.app](https://squoosh.app) — رایگان، داخل مرورگر، بدون نصب
- [tinypng.com](https://tinypng.com) — کشیدن و رها کردن

وقتی بک‌اند وصل شود، سرور خودش این کار را انجام می‌دهد و شما تصویر خام آپلود می‌کنید.

## چقدر فایل می‌توانیم داشته باشیم؟

با **۷۰ آیتم** (یک تصویر + یک فایل برای هرکدام):

| مورد                | فضا          |
| ------------------- | ------------ |
| ۷۰ تصویر بهینه      | ۴ مگابایت    |
| ۷۰ فایل PDF (۲ مگ)  | ۱۴۰ مگابایت  |
| ۷۰ فایل PDF (۵ مگ)  | ۳۵۰ مگابایت  |
| ۷۰ فایل ZIP (۵۰ مگ) | ۳.۴ گیگابایت |

سهمیه فضای ارزان‌ترین هاست: **۱ تا ۵ گیگابایت**.

### آیا حجم زیاد سایت را کند می‌کند؟

**نه.** این دو ربطی به هم ندارند.

وقتی بازدیدکننده صفحه اصلی را باز می‌کند، سرور فقط این‌ها را می‌فرستد:

```
HTML + CSS + JS       ۴۰۶ کیلوبایت
۱۲ تصویر بهینه        ۷۲۰ کیلوبایت
─────────────────────────────────
جمع                   ۱.۱ مگابایت
```

اگر ۳۵۰ مگابایت PDF هم روی سرور باشد، حجم صفحه **دقیقاً همان ۱.۱ مگابایت** می‌ماند. چون بازدیدکننده آن فایل‌ها را درخواست نمی‌کند.

مثل انباری خانه — پر بودنش سرعت رفت‌وآمد شما را کم نمی‌کند.

### پس چه چیزی سایت را از کار می‌اندازد؟

۱. تمام شدن سهمیه **ترافیک** ماهانه
۲. پر شدن کامل دیسک
۳. دانلود همزمان زیاد

هیچ‌کدام با فایل‌های زیر ۱۰ مگابایت و ویدیوهای روی آپارات پیش نمی‌آید.

## آنچه پنل خودکار انجام می‌دهد

| موقعیت                   | واکنش پنل                          |
| ------------------------ | ---------------------------------- |
| لینک آپارات وارد شود     | پخش‌کننده آپارات تنظیم می‌شود      |
| لینک یوتیوب وارد شود     | پخش‌کننده یوتیوب تنظیم می‌شود      |
| لینک گوگل درایو          | به لینک دانلود مستقیم تبدیل می‌شود |
| لینک دراپ‌باکس           | `dl=0` به `dl=1` تغییر می‌کند      |
| فرمت `mp4` + لینک مستقیم | هشدار: بهتر است آپارات باشد        |
| حجم بالای ۵۰ مگابایت     | هشدار: فضای ابری بهتر است          |
| حجم ۱۰ تا ۵۰ مگابایت     | یادآوری که روی سرور مشکلی ندارد    |
| آدرس نامعتبر             | خطا، ذخیره نمی‌شود                 |

## آپلود مستقیم چه زمانی فعال می‌شود؟

گزینه **«آپلود از دستگاه»** در فرم هست ولی غیرفعال است. با اتصال بک‌اند فعال می‌شود و برای **فایل‌های کوچک** (زیر ۱۰ مگابایت) و تصاویر کار خواهد کرد.

ویدیو حتی بعد از آن هم باید روی آپارات بماند — این محدودیت فنی نیست، روش درست همین است.

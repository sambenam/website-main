# چیدمان کارت‌های صفحه اصلی — چرا عنوان کوتاه چیزی را خراب می‌کرد

## مشکل

در بخش «آزمون‌ها»، وقتی عنوان یک آیتم کوتاه بود، آن کارت با بقیه فرق می‌کرد: محتوایش باریک‌تر می‌شد، خط جداکننده پایین کوتاه و وسط‌چین می‌ماند، و خودِ کارت از همسایه‌هایش کوتاه‌تر بود.

نکته این بود که با عنوان‌های موجود اصلاً دیده نمی‌شد. عنوان‌های پیش‌فرض بخش آزمون‌ها همه بین **۳۴ تا ۴۱ کاراکتر** بودند — تقریباً هم‌اندازه. مشکل فقط وقتی ظاهر می‌شد که آیتمی با عنوان کوتاه اضافه می‌شد.

---

## سه علت جداگانه

### ۱. `align-items: center` روی کارت

```css
.exam-news_item {
  display: flex;
  flex-direction: column;
  align-items: center; /* ← این */
}
```

کارت `flex-direction: column` است، پس `align-items` محور **افقی** را کنترل می‌کند، نه عمودی.

نتیجه: `.exam-news_content` به‌جای اینکه تمام عرض کارت را بگیرد، فقط به اندازه متن خودش عرض می‌گرفت و وسط می‌ایستاد.

با عنوان بلند دیده نمی‌شد چون متن خودش کل عرض را پر می‌کرد. با عنوان کوتاه، محتوا جمع می‌شد و خط `meta` هم کوتاه و وسط‌چین می‌ماند.

**رفع:** `align-items: stretch` — که مقدار پیش‌فرض هم هست.

### ۲. کارت ارتفاع نداشت

یک آیتم گرید فقط به اندازه محتوایش بلند می‌شود، مگر اینکه بگویید نه. پس عنوان یک‌خطی، کارت کوتاه‌تری می‌ساخت.

و این یک اثر جانبی داشت: `margin-top: auto` روی ردیف `meta` هیچ فضای خالی‌ای نداشت که خودش را به آن هل بدهد، پس فوتر کارت هم بالا می‌آمد.

**رفع:** `height: 100%` روی کارت.

### ۳. عنوان ارتفاع رزرو نداشت

حتی با ارتفاع یکسان کارت‌ها، عنوان یک‌خطی کنار عنوان دوخطی باعث می‌شد لینک و ردیف `meta` در ارتفاع‌های متفاوت بنشینند.

**رفع:** دو خط رزرو، و سقف دو خط:

```css
min-height: calc(23px * 1.8 * 2); /* = ۸۲.۸ پیکسل */
display: -webkit-box;
-webkit-line-clamp: 2;
-webkit-box-orient: vertical;
overflow: hidden;
overflow-wrap: anywhere;
```

`line-clamp` هم لازم است: بدون آن، یک عنوان خیلی بلند کل ردیف را بلندتر می‌کرد.

## هر چهار بخش درست شد، نه فقط آزمون‌ها

با بررسی معلوم شد **علت دوم در هر چهار بخش** وجود دارد:

| بخش            | قبل                                    | بعد                                       |
| -------------- | -------------------------------------- | ----------------------------------------- |
| دوره‌های محبوب | `height: auto`                         | `height: 100%` + عنوان ۷۶.۸px             |
| دوره‌های جدید  | `height: auto`                         | `height: 100%` + عنوان ۷۶.۸px             |
| مقالات         | `height: auto`                         | `height: 100%` + عنوان ۸۲.۸px             |
| آزمون‌ها       | `height: auto` + `align-items: center` | `height: 100%` + `stretch` + عنوان ۸۲.۸px |

سه بخش اول فقط شانس آورده بودند که عنوان‌هایشان هم‌اندازه بود. اولین آیتم با عنوان کوتاهی که از پنل اضافه می‌کردید، همان مشکل را آنجا هم نشان می‌داد.

## تست

```bash
node tests/card-layout.test.js     # ۲۸ تست
```

پنج چیز را نگه می‌دارد:

1. هر کارت `height: 100%` دارد
2. هر عنوان `min-height` و `line-clamp: 2` دارد
3. کارت آزمون‌ها دیگر `align-items: center` ندارد
4. **در مرورگر واقعی**: چهار عنوان با طول متفاوت، ارتفاع یکسان می‌دهند
5. `height` تصویرها دست‌نخورده مانده (که ربطی به کارت ندارد)

### دو نکته درباره خود تست

تابع خواندن CSS باید `@import` را دنبال کند. `index.html` فایل `main/main.css` را لینک می‌کند که **فقط فهرست `@import` است** — خواندن صرفِ فایل‌های لینک‌شده یک رول‌بوک خالی می‌دهد و همه ادعاها به دلیل اشتباه شکست می‌خورند.

و یک تست اول به **متن کامنت خودم** گیر کرد: کامنتی نوشته بودم که در آن عبارت `align-items: center` بود، و تست آن را با قانون واقعی اشتباه گرفت. کامنت بازنویسی شد.

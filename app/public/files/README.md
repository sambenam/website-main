# پوشه فایل‌های فروشی

فایل‌های دانلودی محصولات (PDF، ZIP، Excel) را اینجا بگذارید.

## آپلود از طریق سی‌پنل

```
سی‌پنل ← File Manager ← public_html ← files ← Upload
```

## آدرس‌دهی در پنل مدیریت

در فرم افزودن محصول، فیلد آدرس فایل:

```
../files/نام-فایل.pdf
```

## 🔒 نکته امنیتی

فایل‌های این پوشه با آدرس مستقیم برای همه قابل دانلودند، حتی کسی که نخریده.

تا زمانی که بک‌اند لینک موقت امضاشده پیاده کند، نام فایل‌ها را غیرقابل حدس بگذارید:

```
❌ hesabdari.pdf
✅ hesabdari-a8f3d9c2.pdf
```

## محدودیت حجم

| حجم              | حکم                      |
| ---------------- | ------------------------ |
| زیر ۱۰ مگابایت   | بدون نگرانی              |
| ۱۰ تا ۵۰ مگابایت | مراقب سهمیه ترافیک باشید |
| بالای ۵۰ مگابایت | فضای ابری بهتر است       |
| ویدیو            | همیشه آپارات             |
